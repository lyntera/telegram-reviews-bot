## 📖 О проекте

**Lyntera Reviews Bot** — это высокотехнологичное решение от **Lyntera Studio**, позволяющее выстроить прозрачный мост между клиентами и вашей аудиторией. Бот автоматизирует сбор обратной связи, защищает ваш канал от нежелательного контента через систему пре-модерации и упаковывает отзывы в эстетичные посты.



## ✨ Ключевые возможности

| Функция | Описание |
| :--- | :--- |
| 📸 **Медиа-альбомы** | Автоматическая склейка нескольких фотографий в единый альбом (MediaGroup). |
| ⭐ **Рейтинг 1-5** | Сбор оценок через интуитивно понятные Inline-кнопки. |
| 🔒 **Приватность** | Выбор формата публикации: публично с тегом или анонимно. |
| 🛡 **Smart-модерация** | Управление контентом из закрытой админ-группы в один клик. |
| 💬 **Фидбек админа** | Возможность указать причину отклонения отзыва, которую бот перешлет автору. |

## 🛠 Технический стек

* **Core:** Python 3.10+
* **Framework:** Aiogram 3.x (Asyncio)
* **Storage:** SQLite (автоматическое создание базы в `reviews.db`)
* **Environment:** Загрузка секретов через `python-dotenv` из файла `token.env`

---

## ⚙️ Конфигурация

Настройте параметры в файле `reviews.py`. Для безопасности токен вынесен в отдельный файл.

| Переменная | Описание | Пример |
| :--- | :--- | :--- |
| `ADMIN_CHAT_ID` | ID группы модераторов. | `-1001234567890` |
| `CHANNEL_ID` | Юзернейм канала для публикации. | `@lyntrev` |
| `BOT_USERNAME` | Юзернейм вашего бота. | `@review_lynbot` |

## 🚀 Установка и запуск

### 1. Подготовка окружения
Создайте в корневой папке файл `token.env` и добавьте туда ваш токен:
```text
BOT_TOKEN=123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11
```
### Важно: Не забудьте добавить token.env в .gitignore, чтобы не опубликовать его в открытый доступ!

Следуйте этой инструкции для быстрого развертывания проекта на вашем сервере или локальном компьютере:

### 1. Подготовка Telegram
1. Создайте бота через [@BotFather](https://t.me/BotFather) и сохраните токен.
2. Создайте **группу для модерации** и добавьте туда бота с правами администратора.
3. Добавьте бота в ваш **публичный канал** с правами на публикацию сообщений.

### 2. Установка зависимостей
Склонируйте репозиторий и установите необходимые библиотеки:
```bash
Установка aiogram
pip install -r requirements.txt
python reviews.py
 ```
### 3. Запуск
После успешного запуска перейдите в бота и введите команду /start.
