## 📖 О проекте

**Reviews Bot** — это разработка **Lyntera Studio**, позволяющая повысить доверие ваших потенциальных клиентов. Бот автоматизирует сбор обратной связи, защищает ваш канал от нежелательного контента через систему пре-модерации и упаковывает отзывы в красивые посты.



## ✨ Возможности бота

| Функция | Описание |
| :--- | :--- |
| 📸 **Медиа-альбомы** | Автоматическая склейка до 10 фотографий в один сгруппированный альбом. |
| ⭐ **Звёздная система оценки** | Сбор оценок через инлайн кнопки после написания самого отзыва и опционального добавления медиафайлов. |
| 🔒 **Приватность** | Выбор формата публикации: публично (с айди пользователя) или анонимно. |
| 🛡 **Ручная модерация** | Одобрение отправки отзывов, работающее внутри админского канала. |
| 💬 **Ответы на отзывы** | Возможность указать причину отклонения отзыва, которую бот перешлёт автору. |

## 🛠 Технический стек

* **Core:** Python 3.10+
* **Framework:** Aiogram 3.x (Asyncio)
* **Storage:** SQLite (автоматическое создание базы в `reviews.db`)
* **Environment:** Загрузка токена бота через `python-dotenv` из файла `token.env`

---

## ⚙️ Конфигурация

Настройте параметры в файле `reviews.py`. Токен вынесен в отдельный файл для вашей же безопасности.

| Переменная | Описание | Пример |
| :--- | :--- | :--- |
| `ADMIN_CHAT_ID` | ID админ канала (тут отзывы до одобрения). | `-1001234567890` |
| `CHANNEL_ID` | Юзернейм канала для публикации (тут отзывы после одобрения). | `@lyntrev` |
| `BOT_USERNAME` | Юзернейм вашего бота. | `@review_lynbot` |

## ⚙️ Установка бота и зависимостей

### 1. Подготовка
Создайте в корневой папке файл `token.env` и добавьте туда ваш токен:

```text
BOT_TOKEN=123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11
```

### 2. Подготовка платформы Telegram:
1. Создайте бота через [@BotFather](https://t.me/BotFather) и сохраните полученный внутри бота токен.
2. Создайте **группу, в которую будут отправляться отзывы до рассмотрения**, после чего добавьте туда бота с правами администратора.
3. Добавьте бота в ваш **публичный канал, в который будут отправляться конечные отзывы,** с правами на публикацию сообщений.

### 3. Установка зависимостей
Склонируйте репозиторий и установите необходимые библиотеки:

```bash
pip install -r requirements.txt
 ```

#### Список зависимостей, необходимых для стабильного запуска бота:
```text
aiogram>=3.0.0
python-dotenv
```

### Важно: Если будете делать свой репозиторий - не забудьте создать .gitignore и указать там файл с токеном, иначе бот улетит в открытый доступ. Также будем признательны, если оставите наш README.md или укажете ссылку на нас <3.

## 🚀 Запуск бота

После запуска пропишите в терминале:

```bash
python reviews.py
```

Дальше переходите по своему `@bot_id`, жмите кнопку старта и наслаждайтесь.
